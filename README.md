# OOP Student Management MVP

## Project Description
This is a simple Java console-based Student Management System developed as an MVP project for Object-Oriented Programming concepts.

## Features
- Add students
- Display students
- Console menu system

## OOP Concepts Used

### 1. Classes and Objects
- Person class
- Student class
- StudentManager class

### 2. Encapsulation
- Private variables
- Getters and setters

### 3. Inheritance
- Student extends Person

### 4. Polymorphism
- displayInfo() method overridden in Student class
